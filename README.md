# PDI

Aplicação JavaFX de Processamento Digital de Imagens.

Os desafios de 2026-02 (porcas, par ou ímpar, comprimidos, círculos e quadrados, ferrugem em
folhas) ficam no menu Desafios e estão descritos em [docs/desafios.md](docs/desafios.md).

## Requisitos

- JDK 26+
- Maven 3.8+

## Executar

```bash
mvn javafx:run
```

## Testes

```bash
mvn test
```

## Build

```bash
mvn compile
```
